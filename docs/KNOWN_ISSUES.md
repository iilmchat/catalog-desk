## Приоритет 1 — блокеры V15

### CD-001 — Нет измерения «сеть/магазин» в модели данных

**Статус:** Fixed в S15–S18 (chain в конфиге, БД и всех запросах UI) · **Спринт:** S15–S18

`products`, `product_details`, `favorites`, `enrichment_tasks` имеют ключ `(sap_code, plu)`,
но не различают сеть. Код SAP (`35XY`, `XSEO`, `47XS`) — это контекст доставки, а не сеть.
При 110 совпадающих PLU между Пятёрочкой и Перекрёстком любые запросы без фильтра
по сети смешивают данные.

**Решение:** добавить `chain` во все таблицы, ключ `(chain, sap_code, plu)`, backfill `chain='5ka'`.

### CD-002 — `EXPECTED_SAP = "35XY"` жёстко зашит в сервере и импортёре

**Статус:** In Progress (EXPECTED_SAP через конфиг; приём SAP — S17) · **Спринт:** S15, S17

`catalog_ui_server_v14.py:38`, `:731`, `:1228`, `import_5ka_catalog_v9.py:998`,
дефолт `--expected-sap 35XY`. Detail-карточки с `sap != 35XY` отклоняются.

### CD-003 — Состав теряется, хотя есть в `details_text`

**Статус:** Fixed в S20 · **Спринт:** S20

В detail-экспорте Перекрёстка (PLU 24139) `composition = null`, при этом полный состав
присутствует в `details_text`. Причина — lookahead с `\n` в
`5ka_export_product_details_bookmarklet_v14.txt:41`, а текст сохранён свёрнутым в одну строку.
Восстанавливается regex без требования перевода строки (проверено).

### CD-004 — БЖУ сдвинуты при порядке «значение → метка»

**Статус:** Fixed в S20 · **Спринт:** S20

В том же файле: `Ккал=14.5`, `Белки=23.0`, `Жиры=4.1`, «Углеводы» отсутствуют;
реальные значения `284.0 / 14.5 / 23.0 / 4.1`. Серверная функция
`parse_nutrition_from_details_text()` исправляет это идеально, **но только для файлов,
прошедших импорт** (см. CD-002).

### CD-005 — `description` никогда не извлекается

**Статус:** Fixed в S20 · **Спринт:** S20

Поле `description` пусто у всех 215 карточек с доп. сведениями, хотя текст описания
есть в `details_text`. Нужен такой же fallback, как для CD-003.

### CD-006 — Пакетное обогащение не видит товары Перекрёстка

**Статус:** Fixed в S17 · **Спринт:** S17

`_batch_pick_next()` (`catalog_ui_server_v14.py:1091`) отбирает только
`product_url.startswith("https://5ka.ru/product/")`; `batch_status()` (`:1125–1131`)
считает только `sap_code=35XY` и `LIKE 'https://5ka.ru/product/%'`.

### CD-007 — userscript привязан к домену 5ka.ru

**Статус:** Fixed в S19 (userscript для perekrestok.ru с guard `pr-v15-*`) · **Спринт:** S17, S19

`@match https://5ka.ru/*`, `LOCAL_API`, `py5ka-*` guard в `sessionStorage`,
`current_sap || '35XY'`. При 110 совпадающих PLU guard без префикса сети пропустит
товары второй сети как уже обработанные.

### CD-008 — Detail-букмаркет запрашивает SAP вручную

**Статус:** Fixed в S19 · **Спринт:** S19

`prompt("Введите SAP-код...", "35XY")`: каталожный экспорт берёт SAP из
`localStorage.DeliveryPanelStore` (`XSEO`), а detail — от пользователя (`47XS`).
Один PLU оказывается под двумя SAP. Нужна автоподстановка из localStorage.

## Приоритет 2 — качество и аналитика

### CD-009 — 110 PLU пересекаются между сетями

**Статус:** Documented · **Спринт:** S15

Это **хорошая новость** для нормализации: PLU — общий идентификатор X5, naming
отличается только оформлением (`БЗМЖ`, запятые). Но сравнение цен обязано быть
привязано к сети и к дате/адресу доставки.

### CD-010 — Маркеры `source` и имена файлов содержат `5ka`

**Статус:** In Progress (импортёр понимает v1/v2 и домен; сборщики — S19) · **Спринт:** S16, S19

Выгрузки Перекрёстка несут `source: "5ka.ru-visible-page-export"` и префикс `5ka_`.
Происхождение записи в БД неверное; нужен нейтральный контракт `visible-*-export` + `chain`.

### CD-011 — Один `enrichment_batch_state` на всю систему

**Статус:** In Progress (добавлен `current_chain`; разделение на строки — S22) · **Спринт:** S17, S22

`enrichment_batch_state` — строка `id=1`. Два параллельных пакета по разным сетям
конфликтуют. Нужна запись на сеть или `chain` в состоянии.

### CD-012 — Шаблон URL товара захардкожен

**Статус:** Open · **Спринт:** S17

`https://5ka.ru/product/.../` с завершающим слешем; у Перекрёстка URL без слеша
и на другом домене.

### CD-013 — Хост фото и Referer захардкожены

**Статус:** Fixed в S16/S17 · **Спринт:** S16, S17

`catalog-images.x5static.net` и `Referer: https://5ka.ru/`. Хост общий, но Referer
должен соответствовать сети; список хостов — конфиг.

## Приоритет 3 — долг и инфраструктура

### CD-014 — Нет автотестов JS-сборщиков

Тестируется только Python. Регексы PLU/категорий/БЖУ и автоподстановка SAP
существуют в трёх независимых местах и легко рассинхронизируются.

### CD-015 — Excel/CSV не содержит колонки «Сеть»

**Статус:** Fixed в S16 · **Спринт:** S16

18 колонок `PRODUCT_COLUMNS` фиксированы; при двух сетях отчёт становится неоднозначным.

### CD-016 — Нет отдельного локального HTTP API для внешних программ

**Статус:** Deferred · **Спринт:** S22

Роуты UI-сервера не являются публичным контрактом; нужна версионированная
обёртка с обязательным параметром `chain`.
