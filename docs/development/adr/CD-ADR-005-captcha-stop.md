# CD-ADR-005. CAPTCHA — остановка, обход запрещён

**Статус:** Accepted · **Дата:** 2026-11-24

## Контекст

Оба сайта X5 показывают антибот-проверку. В userscript V14 уже есть детекция
маркеров (`xpvnsulc`, «пройдите проверку», «а не с ботом» и др.) без попыток её решить.

## Решение

При обнаружении проверки пакет останавливается (`batch_fail(..., captcha=True)`),
в состоянии пишется причина, оператор решает проверку вручную и нажимает
«Возобновить». Запрещены обход CAPTCHA, подмена UA/IP, фермы и увеличение частоты.

## Последствия

+ Соответствие ToS и юридическая безопасность.
+ diagностика вместо тихого пустого результата.
− Поток данных прерывается; альтернатива — ручной импорт (DOM-only bookmarklet).
