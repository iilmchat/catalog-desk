# Pyaterochka Catalog Desk V12.1

V12.1 — локальный интерфейс на Pure JavaScript + Python + SQLite для магазина SAP 35XY.
Добавлены отдельные действия для дозагрузки фотографий и подробных характеристик,
очередь товаров без подробных сведений, галерея изображений в карточке товара,
поддержка дополнительных фото в Excel и история снимков характеристик.

## Установка
1. Остановите старый сервер (Ctrl+C).
2. Сделайте резервную копию рабочей папки.
3. Распакуйте комплект поверх папки проекта. Архив не содержит пользовательскую
   SQLite-базу, фотографии и JSON-выгрузки.
4. Установите зависимости (один раз): `python -m pip install -r requirements_v12.txt`.
5. Запустите `start_ui_v12.bat`.
6. Откройте `http://127.0.0.1:8765`.

## Дозагрузка фото
Раздел «Сбор и импорты» → блок «Фотографии и подробности товаров» → «Дозагрузить фото».
Сервер сканирует URL изображений, уже сохранённые в базе `products` и `product_images`,
и скачивает только отсутствующие локальные файлы. Цена и история цен не изменяются.
После операции пересобираются Excel/CSV.

## Дозагрузка состава и характеристик
1. В очереди товаров без подробных сведений выберите товар и нажмите «Открыть на 5ka.ru».
2. Создайте закладку из полного содержимого `5ka_export_product_details_bookmarklet_v12.txt`.
   Скопируйте строку целиком, включая `javascript:`, в адрес закладки.
3. На открытой карточке товара нажмите закладку, введите SAP 35XY и сохраните JSON.
4. Перетащите JSON в верхнюю область «Добавить JSON-выгрузки».
5. Нажмите отдельную кнопку «Импортировать доп. сведения».

Закладка читает видимые данные открытой страницы и до 12 доступных изображений:
состав, пищевую ценность, вес, сроки, бренд, страну, прочие характеристики и полный текст.
Пустые поля не заполняются догадками. Автоматического обхода CAPTCHA/скрытых страниц нет.

## Дозагрузка галереи
После импорта подробного JSON новые изображения попадут в `product_images`.
Повторно нажмите «Дозагрузить фото» — будут сохранены отсутствующие файлы галереи.
В карточке товара фотографии переключаются стрелками и миниатюрами.

## Файлы и данные
- База V9: `pyaterochka_catalog_v9.sqlite3` — не удалять.
- Фотографии: `photos5ka/` — не удалять.
- Каталожные JSON: `5ka_exports/` — не удалять.
- JSON подробных карточек: `5ka_product_details/`.
- Excel/CSV: пересобираются после импорта и дозагрузки.

Подробная пошаговая инструкция: `QUICK_GUIDE_BACKFILL_V12_1.txt`.

## Проверка проекта
`python -m unittest -v test_catalog_v12.py test_ui_v12.py`

Сервер по умолчанию слушает только `127.0.0.1`.
