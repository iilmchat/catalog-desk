## [Unreleased]

## [V15.1.0] — 2026-11-25

### Fixed
- Основной импорт отклоняет неверный SAP, смешанные сети и URL, принадлежащий другой сети.
- Userscript Перекрёстка адресует batch status/fail явно к `chain=perekrestok`; состояние пакетной обработки разделено по сетям.
- Существующее пакетное состояние V14 переносится в новую таблицу без потери текущей карточки.
- Миграция V9→V10 сохраняет составной внешний ключ `(chain, sap_code, plu)` и проверяет `PRAGMA foreign_key_check`.

### Changed
- Планировщик обозначен как реестр ручных DOM-выгрузок; он не запускает браузер или сбор автоматически.
- Добавлены тесты изоляции очередей, валидации SAP/доменов и внешних ключей.
- Добавлен GitHub Actions CI для Python-тестов и синтаксиса userscript.

### Added
- (записи добавляются в каждом коммите с кодом)

## [V15.0] — 2026-11-25

**Тема:** Catalog Desk становится многомагазинной системой: Пятёрочка + Перекрёсток в одной базе с историей, качеством данных и локальным API.

### Added
- Документация по образцу PriceScope: `README.md`, `GET_STARTED.md`, `TODO.md`,
  `docs/` (хаб, реестр `CD-XXX`, TODO_KI, TODO_SPRINTS, RULES, ARCHITECTURE,
  RELEASES, ADR, дизайн V15, пользовательское руководство и QA-чеклист).
- Git-репозиторий: `.gitignore`, `.gitattributes`, `.editorconfig` — код и документация
  версионируются, база/выгрузки/фотографии исключены.
- S15: `catalog_config.py` — реестр сетей `5ka`/`perekrestok` (домены, префиксы URL,
  хосты фото, SAP, `source`-маркеры, пути); `catalog_migrations.py` — миграция V9→V10
  с добавлением `chain`, расширением ключей и одноразовым бэкапом; 6 новых тестов
  (`test_catalog_config_v15.py`).

### Added
- S16: контракт Export v2 (`schema_version=2`, `chain`) с чтением v1; сеть определяется
  по явному полю, затем по домену URL, затем по маркеру `source`; `--chain` и
  `--input-dir` в импортёре; колонка «Сеть» во всех листах Excel и в CSV;
  2 новых теста (`test_import_v2_v15.py`).

### Changed
- Зафиксирован план V15: многомагазинная модель, конфиг магазинов, импорт
  Перекрёстка, качество данных (состав/БЖУ), аналитика и сравнение.
- Импорт Перекрёстка проверен на реальной выгрузке: 432 товара под `perekrestok/XSEO`,
  111 старых цен, 110 PLU пересекаются с Пятёрочкой без перезаписи.
- Пути выгрузок/фото, Referer и хосты фото в импортёре берутся из конфига сети;
  для неосновной сети создаются `catalog_<chain>_v10.xlsx/.csv/_report.json`.
- S17: сервер принимает `chain` во всех основных роутах; очередь, карточка,
  поиск, избранное, аналитика, дашборд и история цен фильтруются по сети;
  `_batch_pick_next()` выбирает товары по префиксу URL сети; `batch_record()` и
  `import_pending_details()` принимают SAP обеих сетей и пишут `chain`;
  загрузка JSON и дозагрузка фото работают по папкам сетей; 2 новых теста
  (`test_server_multi_store_v15.py`).

### Changed
- `EXPECTED_SAP` заменён на проверку «SAP разрешён для сети»; состояние пакета
  получило поле `current_chain`.
- Подмена `BASE_DIR` в тестах теперь уважается всеми путями сетей.
- S18: переключатель сети в шапке (`/api/stores`), `chain` во всех запросах UI
  (GET-параметр и POST-тело), динамические подписи/логотип, сравнение одного PLU
  между сетями (`/api/compare`); интерфейс обновлён до V15.0 без копирования `ui_v14`.
  Тест реестра и сравнения добавлен, 75 тестов зелёные.
- S19: bookmarklet'ы `pr_export_*` и `pr_batch_enrichment_v15.user.js` для
  `perekrestok.ru`: `chain='perekrestok'`, новые `source`-маркеры, SAP из
  `localStorage` с fallback `XSEO`, guard `pr-v15-*`, ссылки в интерфейсе;
  3 теста на маркеры/домены и синтаксис JS, 78 тестов зелёные.
- S20: серверное восстановление состава и описания из `details_text`, индикатор
  полноты (8 полей + источник сведений), проверка противоречий массы/объёма,
  кнопка «Повторно загрузить карточку»; одноразовая миграция `quality_repair_v15`;
  4 теста на карточке 24139, 82 теста зелёные.
- S21: `/api/search` (условия «без сахара», «белки больше N», «жиры меньше N»,
  «срок хранения больше N», «содержит …», бренд, цена), `/api/ingredients`
  с эвристиками и оговоркой про анализ текста, `/api/compare-table` с ценой за кг;
  новый раздел «Поиск по составу» в интерфейсе; 83 теста зелёные.
- S22: журнал ошибок `operation_errors`, расписание `daily_runs`, бэкап по кнопке,
  версионированный локальный API `/api/v1/*` с обязательной сетью, панель
  автоматизации в «Сборе и импортах»; 84 теста зелёные.
- `catalog_ui_server_v14.py` и `import_5ka_catalog_v9.py` применяют миграцию V10
  при старте/импорте; `ON CONFLICT` переведены на ключи с `chain`.
- `EXPECTED_SAP` берётся из конфига сети по умолчанию вместо литерала `35XY`.

## [14.0] — 2026-11-24

**Тема:** пакетное обогащение карточек через userscript и контроль качества БЖУ/галерей.

### Added
- `5ka_batch_enrichment_v14.user.js`: последовательное открытие карточек, лимит
  1–200, пауза 12–60 сек, останов при CAPTCHA, продолжение пакета.
- Восстановление БЖУ из `details_text` при обоих порядках («3.5 Белки» и «Белки 3.5»),
  игнорирование знаменателя «на 100 г/мл».
- Очистка галерей от фотографий рекомендательных блоков, отбор по `alt` и позиции.
- Одноразовый бэкап базы перед миграцией: `pyaterochka_catalog_v9.pre_v14_backup.sqlite3`.
- Возврат неполных старых карточек в очередь обогащения.
- Интерфейс: панель пакетного режима, прогресс, кнопки «Начать/Пауза/Продолжить».

### Fixed
- Сдвинутые значения БЖУ в старых снимках исправляются при старте сервера.
- Старые detail-ссылки на рекомендательные фотографии удаляются один раз.

### Known limitations
- Только одна сеть: `SAP 35XY`, домен `5ka.ru`, маркеры `source` с префиксом `5ka`.
- Detail-карточки с другим SAP отклоняются импортом.
- Состав и описание могут отсутствовать, даже если видны на странице (CD-003, CD-005).
- новая сеть требует изменений кода, а не только конфигурации.

## [9.0] — 2026-11-24

**Тема:** накопительная SQLite-база и история цен.

  Excel (9 листов) и CSV.
- Таблицы `products`, `price_history`, `product_categories`, `exports`.
