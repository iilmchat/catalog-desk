# Реестр технических рисков Catalog Desk

**Актуально для V17 foundation + S23 DOM regression follow-up (2026-11-26).** Статусы ниже сверяются с реализацией и автоматическими тестами.

## Исправления V15.1

### CD-017 — Основной импорт принимал SAP другой сети
**Статус:** Fixed. Импортёр проверяет SAP по реестру сети, однородность `chain` внутри файла и домен источника/карточки до транзакции.

### CD-018 — Userscript Перекрёстка читал состояние Пятёрочки
**Статус:** Fixed. Все обращения userscript к batch status/fail передают `chain=perekrestok`.

### CD-011 — Одно состояние пакетного сбора на всё приложение
**Статус:** Fixed. Добавлена таблица `enrichment_batch_states` с ключом сети; старое состояние переносится из V14.

### CD-019 — Миграция V9→V10 теряла внешние ключи
**Статус:** Fixed. Ограничение категорий на товар расширено до `(chain, sap_code, plu)`; после миграции выполняется `PRAGMA foreign_key_check`.

### CD-020 — Нет автоматической проверки изменений
**Статус:** Implemented. GitHub Actions запускает Python unittest, проверяет синтаксис четырёх копий userscript, Node.js helper regression tests для обеих сетей и Python-тесты сохранённых DOM-фикстур. Полноценный browser-like DOM runtime harness остаётся отдельной задачей CD-025.

### CD-026 — Полнота данных не учитывает применимость атрибутов
**Статус:** V17 foundation implemented. Добавлены классы food / pet_food / non_food / unknown, статусы применимости и результаты извлечения; N/A исключается из знаменателя, unknown не приравнивается к N/A. Generic «Состав» для non-food сохраняется как материалы. Метаданные находятся в `attributes_json._catalog_meta`, без миграции SQLite. Реальные сокращённые DOM-фикстуры non-food и Пятёрочки уже добавлены; дальнейшая работа — расширять taxonomy map и category-specific quality profiles только по новым наблюдаемым категориям. Schema migration отложена.

## Осознанные ограничения

### CD-021 — Планирование не запускает сбор самостоятельно
**Статус:** Documented. `daily_runs` — реестр запланированных ручных DOM-выгрузок. Он не открывает браузер и не запускает сбор в фоне.

### CD-022 — Одновременная работа браузерных сборов
**Статус:** Documented. Состояния очередей независимы по сети, однако пользователю следует контролировать вкладки и профиль браузера; один userscript не должен конкурировать сам с собой за одну очередь.

### CD-023 — Автоматический анализ состава эвристический
**Статус:** Documented. Поиск ингредиентов и маркеров основан на тексте состава, не является лабораторной проверкой или медицинской оценкой.

### CD-024 — Неполное извлечение деталей карточки Перекрёстка
**Статус:** Partially mitigated / source limitation confirmed. Реальная DOM-фикстура PLU 4406119 / SAP XSEO подтверждает product root, цену, изображения, БЖУ и характеристики; в ней отсутствуют состав и отдельное фактическое описание. Фикстура PLU 4414429 подтверждает non-food материалы «Полиэтилен, джут.», но не содержит описания. Userscript ограничивает извлечение узлом `[data-qa="product-screen"]` и исключает соседние рекомендации. Для закрытия нужны дополнительные captured pages, где описание и состав действительно присутствуют или свёрнуты, с проверкой раскрытого/нераскрытого состояния.

### CD-025 — DOM regression userscript и сборка payload
**Статус:** Partially mitigated; automated regression baseline implemented. PR #9 добавил LinkeDOM harness (7 сценариев); PR #10 добавил Chromium smoke harness (3 сценария) на captured pages. GitHub Actions CI #140 прошёл успешно: 122 Python-теста, JS syntax checks, LinkeDOM и Chromium. Отдельно выполнен ручной live single-refresh smoke на реальных карточках Пятёрочки PLU `4275044` и Перекрёстка PLU `4414429`: оба обновления подтверждены уведомлением userscript, массовая очередь не затронута. Это подтверждает путь одноразового обновления на двух сетях, но ещё не является полевым аудитом каждого извлечённого значения и не проверяет реальное раскрытие описания на сайте. Следующий этап — проверить видимые/свёрнутые секции Перекрёстка и сохранять обезличенные fixtures после проверки источника. SQLite migration и массовое обогащение не входят в этот этап.
