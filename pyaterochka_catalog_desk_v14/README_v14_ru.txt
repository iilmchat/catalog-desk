PYATEROCHKA CATALOG DESK V14.0
================================

ВНИМАНИЕ
--------
V14 использует существующую базу pyaterochka_catalog_v9.sqlite3. Она не
заменяется и не пересоздаётся заново. Перед первой миграцией сервер автоматически
создаёт файл pyaterochka_catalog_v9.pre_v14_backup.sqlite3, если его ещё нет.
Дополнительно рекомендуется сделать копию всей рабочей папки.

ЧТО НОВОГО
----------
1. Пакетное обогащение через Tampermonkey/Violentmonkey. Userscript ставится
   один раз. После нажатия «Начать пакет» браузер сам последовательно открывает
   обычные страницы товаров и импортирует видимые сведения. Нажимать закладку
   отдельно на каждом из 2 494 товаров не нужно.
2. Лимит одного пакета — до 200 карточек; задержка — 12-60 секунд. Для 2 494
   товаров потребуется ориентировочно 13 запусков пакетов по 200, последний
   будет короче. После пакета используется «Продолжить / следующий пакет».
3. При CAPTCHA или ошибке страницы пакет останавливается. Обхода проверок,
   автоматического решения CAPTCHA, скрытых API 5ka и параллельных запросов нет.
4. Исправлен разбор БЖУ: поддерживаются оба порядка (3.5 Белки и Белки 3.5),
   ккал тоже распознаются. Значение 100 из «на 100 г/мл» игнорируется.
5. При старте миграция чинит старые nutrition_json и макросы в attributes_json
   из сохранённого полного текста details_text. Снимки истории тоже исправляются.
6. Старые галереи чистятся от дополнительных ссылок, собранных с рекламного
   блока. Впоследствии новые фотографии отбираются с проверкой alt и позиции
   относительно заголовка рекомендаций.
7. Неполные старые карточки возвращаются в очередь обогащения один раз.

УСТАНОВКА
---------
1. Остановите старый Catalog Desk через Ctrl+C.
2. Сделайте резервную копию рабочей папки.
3. Распакуйте СОДЕРЖИМОЕ ZIP в существующую папку:
   C:\Tools\ParserPyaterka\pyaterochka_project_v7
   Не удаляйте базу, photos5ka, 5ka_exports, 5ka_product_details и файл
pyaterochka_catalog_v9.pre_v14_backup.sqlite3 после первого запуска.
4. Если зависимости уже стоят, повторная установка не нужна. Иначе выполните:
   python -m pip install -r requirements_v14.txt
5. Запустите start_ui_v14.bat. Адрес: http://127.0.0.1:8767

УСТАНОВКА USERSCRIPT (ОДИН РАЗ)
-------------------------------
1. Установите Tampermonkey или Violentmonkey.
2. Откройте расширение -> Create new script / Создать новый скрипт.
3. Откройте 5ka_batch_enrichment_v14.user.js в Блокноте, скопируйте всё
   содержимое в редактор расширения, сохраните Ctrl+S и включите скрипт.
4. Расширение должно разрешать выполнение на https://5ka.ru.
5. В Catalog Desk откройте «Массовое обогащение», выберите категорию, лимит
   и паузу; нажмите «Начать пакет». Откроется вкладка товара. Дальше переходы
   и импорт выполняются автоматически по одному товару за раз.
6. Для первого теста: 10-20 товаров и пауза 15-20 секунд. После проверки
   можно увеличить лимит до 50-100, затем до 200.
7. После завершения пакета нажмите «Продолжить / следующий пакет». Если сайт
   потребовал CAPTCHA, пройдите её вручную и возобновите пакет.

ДАННЫЕ И ОГРАНИЧЕНИЯ
--------------------
- Сбор читает DOM только открытой страницы обычного браузера.
- Состав, БЖУ и свойства сохраняются только если они видны в карточке товара.
- Рекомендательные блоки исключаются из фото-галереи; на старте V14 удаляет
  старые detail-ссылки, кроме URL основной фотографии из товарной записи.
- Некоторые страницы могут не содержать полного состава или характеристик;
  импортированная карточка в таком случае останется заполненной частично.
- Фото можно дозагрузить через кнопку в «Сбор и импорты».
- Время снимков и импорта хранится в UTC.
- Локальный сервер доступен только на 127.0.0.1:8767.
