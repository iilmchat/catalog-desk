**Дата:** 2026-11-24
**Тип:** разведка перед S15 (код не изменялся)

## 1. Файлы

Прочитаны: `catalog_ui_server_v14.py` (1 723 строки), `import_5ka_catalog_v9.py`
(1 101), `ui_v14/`, bookmarklet'ы, userscript, `pyaterochka_catalog_v9.sqlite3`.

## 2. Покрытие

Автотесты не изменялись. Проверки performed через существующие функции:
`parse_visible_card()`, `parse_nutrition_from_details_text()`, SQL-запросы к копии базы.

## 3. Результаты

- Каталожный экспорт Перекрёстка: 432/432 цен распознаны существующим `PRICE_RE`,
  111 старых цен, 122 промо, 119 процентов скидки.
- PLU/Category regex, хост `catalog-images.x5static.net`, формат URL `--<PLU>` совпадают.
- 110 из 432 PLU присутствуют в базе Пятёрочки (в основном тот же товар,
  отличается оформление названия).
- Detail-файл: `composition = null` при полном составе в `details_text`;
  БЖУ сдвинуты (`Ккал 14.5` вместо `284.0`, потеряны «Углеводы»);
  `parse_nutrition_from_details_text()` возвращает корректные значения.
- Текущий импорт отклоняет detail с `sap != 35XY` (`catalog_ui_server_v14.py:731`),
  а batch — ещё и по URL `5ka.ru` (`:1091`, `:1125`, `:1228`).

## 4. Smoke

Экспорт сделан вручную в браузере на `www.perekrestok.ru/catalog/...--268C62016?page=12`;
SAP `XSEO` подставлен bookmarklet'ом из `localStorage.DeliveryPanelStore`.
SAP `47XS` в detail-файле — ручной ввод в `prompt`, не автоматика скрипта.
