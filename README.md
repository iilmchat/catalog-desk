# Catalog Desk V14.0

**Локальная аналитическая система товарного каталога: история цен, состав, БЖУ, фотографии и качество данных.**

© 2026 Catalog Desk · V14.0

---

## Что это

Catalog Desk превращает ручные выгрузки из браузера в управляемую локальную базу:

- **Сбор только из DOM открытой страницы** — bookmarklet'ы и userscript не обращаются к внутренним API магазина, не читают cookies и не обходят CAPTCHA;
- **Накопительная история цен** — каждое новое наблюдение попадает в `price_history`, повтор файла с тем же SHA-256 пропускается;
- **Дополнительные сведения карточки** — состав, БЖУ, вес, срок хранения, бренд, галерея фотографий;
- **История изменений карточки** — каждый импорт дополнительных сведений сохраняет снимок;
- **Очередь обогащения** — товары без состава/характеристик возвращаются в работу;
- **Пакетный режим V14** — userscript сам открывает карточки по одной, останавливается на CAPTCHA;
- **Локальный веб-интерфейс** на `http://127.0.0.1:8767` — каталог, аналитика, сравнение цен, карточка товара, экспорт.

Сейчас в базе данные только Пятёрочки (`SAP 35XY`). Подключение Перекрёстка (`perekrestok.ru`) — следующий этап, см. [TODO.md](TODO.md).

## Требования

| Компонент | Версия |
| :--- | :--- |
| Python | 3.10+ (проверено на 3.12) |
| Зависимости | `pandas`, `requests`, `Pillow`, `openpyxl` — `requirements_v14.txt` |
| Браузер | Chrome / Firefox / Edge + Tampermonkey или Violentmonkey |
| SQLite | встроен в Python, отдельно не ставится |
| ОС | Windows (стартовый `.bat`), сервер слушает только `127.0.0.1` |

Никаких API-ключей, серверных компонентов и внешних сервисов нет.

## Быстрый старт

```powershell
python -m pip install -r requirements_v14.txt
.\start_ui_v14.bat
# открыть http://127.0.0.1:8767
```

Рабочий процесс:

1. Открыть категорию `5ka.ru` в браузере, подгрузить товары («Показать ещё»).
2. Запустить bookmarklet экспорта текущей страницы из `ui_v14/`.
3. В Catalog Desk: «Сбор и импорты» → загрузить JSON → «Обновить базу».
4. Для состава/БЖУ — «Массовое обогащение» → «Начать пакет» (нужен userscript).
5. Аналитика, поиск и экспорт — в соответствующих разделах интерфейса.

Подробно — [GET_STARTED.md](GET_STARTED.md) и [USER_GUIDE.md](docs/user_guide/USER_GUIDE.md).

## Архитектура (коротко)

```
браузер (DOM) → bookmarklet / userscript → JSON-снимки
      → import_5ka_catalog_v9.py → SQLite → catalog_ui_server_v14.py → ui_v14 (HTTP + JS)
      → Excel / CSV
```

Рабочие файлы:

| Файл | Роль |
| :--- | :--- |
| `catalog_ui_server_v14.py` | HTTP-сервер, API, миграции, импорт карточек, пакетное обогащение |
| `import_5ka_catalog_v9.py` |импорт выгрузок каталога в SQLite, история цен, Excel/CSV |
| `ui_v14/` | интерфейс (`index.html`, `app.js`, `style.css`) и скрипты сбора |
| `pyaterochka_catalog_v9.sqlite3` | рабочая база (в git не коммитится) |
| `5ka_exports/`, `5ka_product_details/`, `photos5ka/` | данные и фотографии (в git не коммитятся) |

Подробно — [ARCHITECTURE.md](docs/development/ARCHITECTURE.md).

## Политика сбора

- Собирается **только то, что уже видно на открытой странице**; запросы к API, обход CAPTCHA и эмуляция действий запрещены.
- При обнаружении CAPTCHA пакет останавливается; продолжение — только вручную после решения проверки.
- Цены относятся к онлайн-каталогу для выбранного адреса доставки и могут отличаться от цены на полке.
- Фотографии рекомендаций («Вам понравится», «Похожие товары») не привязываются к товару.
