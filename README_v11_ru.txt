ПЯТЁРОЧКА — CATALOG DESK V11
============================
Локальная товарная база для выбранного магазина SAP 35XY.
Интерфейс: Python (стандартная библиотека) + Pure JavaScript + SQLite.
Без Node.js, npm, React, CDN и облачных сервисов.

ЧТО НОВОГО В V11
----------------
1. Переработана карточка товара: крупная фотография, цена и акция, даты появления
   и импорта, история цены, отдельные блоки состава, пищевой ценности и характеристик.
2. Добавлен импорт подробных сведений со страницы товара 5ka.ru:
   вес, срок и условия хранения, бренд, страна, тип продукта, упаковка, состав,
   белки/жиры/углеводы/энергетическая ценность и другие видимые поля.
3. Доп. сведения хранятся отдельно в SQLite в product_details и product_detail_history.
   Повторный экспорт того же файла не создаёт дубль; новый снимок сохраняется в истории.
4. Добавлены избранное (сохраняется в SQLite), аналитика средней цены/скидки,
   список сильных подорожаний и удешевлений, топ скидок.
5. Расширен контроль полноты: категории, страницы, оценка пропусков пагинации.
6. В Excel добавлен отдельный лист «Подробные сведения».
7. Импорт остаётся доступен одной кнопкой в браузере. Фото можно не перекачивать.

ВАЖНО ПРО ДОПОЛНИТЕЛЬНЫЕ СВЕДЕНИЯ
---------------------------------
Обычная страница категории содержит не все характеристики. Состав, БЖУ, вес,
срок хранения и свойства показаны на странице конкретного товара.
Поэтому V11 добавляет отдельную закладку для открытой карточки товара.

Экспорт дополнительных сведений выполняется вручную для выбранного товара:
- открыть страницу товара на 5ka.ru;
- нажать закладку «Экспорт подробной карточки V11»;
- в появившемся окне ввести SAP-код магазина (например, 35XY);
- браузер скачает JSON 5ka_detail_SAP_PLU_*.json;
- перетащить JSON в Catalog Desk → «Сбор и импорты»;
- нажать «Импортировать».

Закладка считывает только видимый DOM уже открытой страницы. Она не вызывает API,
не обходит CAPTCHA и не переходит автоматически по другим товарам. Если характеристика
не присутствует или скрыта на странице, она не может быть гарантированно извлечена.
В карточке интерфейса дополнительно доступен полный текст страницы, собранный закладкой.

УСТАНОВКА В СУЩЕСТВУЮЩИЙ ПРОЕКТ V9/V10
--------------------------------------
1. Сделайте резервную копию папки проекта, особенно SQLite и photos5ka.
2. Распакуйте ZIP V11 поверх папки, в которой лежит pyaterochka_catalog_v9.sqlite3.
   Например: C:\Tools\ParserPyaterka\pyaterochka_project_v7
3. Не удаляйте и не заменяйте:
   - pyaterochka_catalog_v9.sqlite3
   - 5ka_exports\
   - photos5ka\
   - pyaterochka_catalog_v9.xlsx / CSV (если хотите сохранить прошлые отчёты).
4. ZIP не содержит SQLite и папку photos5ka. Он добавляет только программу,
   интерфейс, закладки, инструкции и последнюю JSON-выгрузку категории «Рыба и морепродукты».
5. Обновлённый import_5ka_catalog_v9.py сохраняет совместимость с БД V9 и добавляет
   в XLSX лист «Подробные сведения», если они уже импортированы через интерфейс V11.
6. При первом старте V11 создаёт недостающие таблицы IF NOT EXISTS и два поля пагинации
   в exports. Существующие товары, цены и история не удаляются.

ЗАПУСК
------
Дважды щёлкните:
   start_ui_v11.bat

Или из PowerShell:
   python catalog_ui_server_v11.py

Откроется:
   http://127.0.0.1:8765

Сервер доступен только на этом компьютере (127.0.0.1). Пока окно сервера открыто,
интерфейс работает. Для остановки нажмите Ctrl+C.

РАЗДЕЛЫ ИНТЕРФЕЙСА
------------------
- Обзор: товары, скидки, фотографии, доп. сведения и последние импорты.
- Каталог: поиск по названию/PLU, фильтры, сортировка, отметка доп. сведений,
  избранное и подробная карточка товара.
- Аналитика: средняя цена и скидка по датам наблюдений, самые большие изменения,
  товары с максимальными скидками.
- Изменения цен: последовательные наблюдения одного SAP+PLU.
- Избранное: личный список товаров, сохранённый в SQLite.
- Сбор и импорты: загрузка JSON, импорт, журнал и оценка покрытия категорий/страниц.

ИСТОРИЯ И АНАЛИТИКА
-------------------
История цен начинается с первого импортированного снимка. Новое наблюдение того же PLU
создаёт следующую точку. Изменения определяются сравнением последовательных снимков.
История подробных характеристик ведётся отдельно: первый/последний импорт и снимки.
Время наблюдения и время импорта не смешиваются; время хранится в UTC.

Средняя цена в аналитике — простое среднее по товарам, попавшим в наблюдения данного дня.
Состав выборки между днями может отличаться; это индикатор динамики выгрузок, а не индекс
цен сопоставимой корзины. Скидки и цены относятся к онлайн-каталогу выбранного адреса,
а не гарантируют стоимость на полке физического магазина.

ПОЛНОТА СБОРА
-------------
Закладка каталога экспортирует товары, уже отображённые на текущей странице, и номера
ссылок пагинации, видимые в DOM. Чтобы покрыть категорию, нужно открыть и экспортировать
каждую страницу отдельно. Максимум страниц и список пропусков — оценка по видимой пагинации,
не гарантированное сервером общее число страниц.

БЕЗОПАСНОСТЬ И ОГРАНИЧЕНИЯ
-------------------------
- Сервер слушает только 127.0.0.1; не меняйте host на 0.0.0.0.
- JSON сохраняется локально. Сервер не отправляет базу в облако.
- Детальный экспорт — только открытая карточка и видимый DOM.
- CAPTCHA не обходится; при проверке сайта остановитесь и выполните её штатно вручную.
- V11 не выполняет автоматическую навигацию по всем товарам/страницам сайта.
