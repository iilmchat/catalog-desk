ПЯТЁРОЧКА — ЭТАП V9: ДАТА ПОЯВЛЕНИЯ + ДАТА ИМПОРТА + ИСТОРИЯ ИЗМЕНЕНИЙ
============================================================================

ЧТО НОВОГО
----------
V9 разделяет два времени:
  1) Дата первого появления — время снимка каталога (captured_at), когда PLU
     впервые замечен в одной из выгрузок.
  2) Дата первого импорта — фактическое время, когда JSON был добавлен в SQLite.

Также хранятся дата последнего наблюдения и дата последнего импорта.
Каждая строка истории содержит оба времени, цену, обычную цену, промоцену,
скидку, маркер акции, название и изображение на момент новой выгрузки.

ЛИСТЫ EXCEL
-----------
Товары                — актуальная карточка, даты первого/последнего появления
                        и импорта, число наблюдений.
Сводка                — количество товаров, фото, наблюдений, событий и даты.
История цен           — все снимки с датой наблюдения И датой импорта.
Изменения цен         — дата предыдущего снимка, дата нового снимка, дата импорта,
                        предыдущая/новая цена, обычная/акционная цена и скидка.
События карточек      — первое появление товара, а также изменения цены,
                        акции, названия, фото, ссылки и категории.
Прогресс категорий    — выгруженные категории и страницы.
Экспорты              — дата снимка и фактическая дата импорта каждого JSON.

МИГРАЦИЯ И ДАННЫЕ
-----------------
1. Скопируйте файлы V9 в существующую папку проекта, рядом с 5ka_exports и photos5ka.
2. Не удаляйте pyaterochka_catalog_v8.sqlite3, JSON-выгрузки и фотографии.
3. При первом запуске V9 создаст pyaterochka_catalog_v9.sqlite3 и скопирует в неё
   старую V8 базу через SQLite backup API. Исходный файл V8 останется нетронутым.
4. Даты импорта старых V8 наблюдений восстанавливаются из таблицы exports.imported_at.
   V8 не хранила исторические названия/фото в каждой строке истории. Поэтому при
   миграции старых строк имя и фото заполняются последним известным значением;
   реальные исторические названия/изображения появятся только в новых V9 снимках.
5. Одинаковый JSON не импортируется повторно: используется SHA-256. Новая выгрузка
   (новый файл/страница/дата) добавит новое наблюдение.

ЗАПУСК
------
  python -m pip install pandas requests pillow openpyxl
  python -m unittest -v test_import_5ka_v9.py
  python import_5ka_catalog_v9.py

Без проверки/скачивания фото:
  python import_5ka_catalog_v9.py --no-photos

Время хранится в UTC в ISO 8601. Дата наблюдения берётся из captured_at JSON;
дата импорта выставляется часами компьютера в момент фактического импорта.

ВАЖНО
-----
История не может восстановить события до первого доступного снимка. Для фиксации
изменения цены того же товара нужны повторные экспорты того же PLU в разные даты.
Экспорт закладки содержит только товары, уже отображённые в DOM текущей страницы.
Страницы категории нужно выгружать отдельно через обычный браузер.
Цены относятся к онлайн-каталогу выбранного адреса доставки и могут отличаться
от цены на полке физического магазина.
