# Отчёты по шагам

Отчёт создаётся для каждого выполненного шага [TODO.md](../../TODO.md)
в папке `v15/`: `S15_config_and_chain.md`, `S16_import_v2.md`, … .

## Шаблон (7 разделов)

1. **Файлы** — что добавлено/изменено, с путями.
2. **Покрытие** — какие тесты добавлены, на какой фикстуре.
3. **Результаты** — команды и вывод (`unittest`, smoke, SQL-проверки).
4. **Smoke** — ручной сценарий в браузере/интерфейсе.
5. **Что не так** — риски, незакрытые `CD-XXX`.
6. **Новые CD** — записи в [KNOWN_ISSUES.md](../../KNOWN_ISSUES.md).
7. **Обоснование** — ссылки на ADR и альтернативы.
