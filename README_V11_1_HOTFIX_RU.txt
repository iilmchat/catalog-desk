PYATEROCHKA CATALOG DESK — HOTFIX V11.1

Что исправлено:
1. Навигация: скрытие неактивных разделов и явное переключение текущей страницы.
2. Каталог и избранное: двойной щелчок по строке открывает карточку товара; кнопки внутри строки продолжают работать отдельно.
3. Кодировка: импортёр запускается с PYTHONIOENCODING=utf-8 и PYTHONUTF8=1; текстовые статические файлы отдаются с charset=utf-8.
4. BAT включает UTF-8 для окна Windows.

Установка:
1. Закройте старое окно сервера V11 (Ctrl+C).
2. Сделайте резервную копию папки проекта.
3. Распакуйте этот архив поверх проекта, сохраняя структуру папок.
4. Запустите start_ui_v11.bat.
5. Откройте http://127.0.0.1:8765 и нажмите Ctrl+F5.

База SQLite, JSON-выгрузки и папка photos5ka не заменяются этим hotfix-архивом.
