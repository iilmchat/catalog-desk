# CD-ADR-001. Сбор только из DOM открытой страницы

**Статус:** Accepted · **Дата:** 2026-11-24

## Контекст

X5-сайты защищены антиботом. Внутренние API Пятёрочки и Перекрёстка разные
(`5d.5ka.ru/api` против `www.perekrestok.ru/api/customer/1.4.1.0`), требуют
нестандартных заголовков и sessions. README_v7 уже описывает отказ от
неофициальных API-библиотек.

## Решение

Bookmarklet'ы и userscript читают только DOM уже отрисованной страницы в обычном
браузере пользователя: `a[href*="/product/"]`, `img`, `h1`, текст карточки.
Никаких запросов к API, чтения cookies, обхода CAPTCHA и эмуляции кликов.

## Последствия

+ Работает в пользовательской сессии, где антибот уже пройден.
+ Один и тот же подход применим к обеим сетям X5.
+ Полнота зависит от того, что реально видно на странице (CD-003, CD-005).
− Нужны ручные действия: открыть категорию, подгрузить товары, решить CAPTCHA.

См. также [CD-ADR-005](CD-ADR-005-captcha-stop.md).
