ПЯТЁРОЧКА — ЭТАП V7: РУЧНОЙ ЭКСПОРТ ВИДИМОГО КАТАЛОГА + EXCEL
================================================================

Зачем изменён способ сбора
--------------------------
Предыдущий автоматический клиент pyaterochka_api не является официальным API.
Его README прямо описывает имитацию сетевой работы браузера. В пользовательской
сессии X5 уже показывал антибот-проверку. Поэтому v7 не делает запросов к API
5ka.ru и не пытается проходить/обходить CAPTCHA. Вместо этого пользователь
сам открывает страницы сайта обычным браузером и экспортирует только те карточки,
которые сайт уже показал в текущей вкладке.

Файлы
-----
1) 5ka_export_current_page_bookmarklet.txt
   Однострочный bookmarklet — код для кнопки-закладки в Firefox/Chrome.
   Он читает DOM текущей страницы и сохраняет JSON. Не читает cookies, не делает
   fetch/XHR, не нажимает кнопки сайта и не переключает категории.

2) 5ka_export_current_page.js
   Читаемая версия исходного кода bookmarklet.

3) 5ka_export_categories_bookmarklet.txt + 5ka_export_categories.js
   Необязательная закладка: на странице https://5ka.ru/catalog/ сохраняет список
   ссылок на категории, которые уже отображены в каталоге. Это чек-лист для
   ручной навигации; скрипт не обходит страницы автоматически.

4) import_5ka_exports_v7.py
   Объединяет JSON-экспорты, старый pyaterochka_checkpoint.jsonl и необязательные
   файлы из catalog_json. Создаёт Excel/CSV и скачивает фото по публичным URL,
   которые уже присутствовали в экспортированной карточке.

КАК УСТАНОВИТЬ BOOKMARKLET
--------------------------
Firefox:
1. Откройте 5ka.ru в обычном Firefox.
2. Нажмите Ctrl+Shift+O (управление закладками).
3. Создайте новую закладку в панели закладок.
4. Имя: Экспорт карточек 5ka.
5. В поле URL/Адрес полностью вставьте содержимое файла
   5ka_export_current_page_bookmarklet.txt (начинается с javascript:).
6. Сохраните.

Chrome/Chromium:
1. Включите панель закладок (Ctrl+Shift+B).
2. Добавьте закладку; в поле URL вставьте ту же строку javascript:...
3. Сохраните.

Необязательно: создайте вторую закладку «Экспорт категорий» из файла
5ka_export_categories_bookmarklet.txt. Откройте https://5ka.ru/catalog/ и нажмите
её, чтобы сохранить JSON со ссылками на категории, видимые на этой странице.
Он служит чек-листом и не импортируется как товарный файл.

КАК СОБРАТЬ КАТЕГОРИИ
---------------------
1. Откройте https://5ka.ru обычным браузером.
2. На сайте задайте нужный адрес доставки/магазин. До экспорта проверьте, что
   выбран тот же магазин, который нужен проекту. Ранее API показывал код SAP
   35XY, но название магазина API не передал.
3. Откройте страницу категории каталога.
4. Дайте странице полностью отобразить товары. Если есть кнопка «Показать ещё»,
   нажимайте её вручную; если используется прокрутка, прокручивайте вручную,
   пока новые товары перестанут появляться.
5. Нажмите закладку «Экспорт карточек 5ka».
6. Браузер скачает JSON. Переместите его в папку 5ka_exports рядом со скриптом.
7. Повторите для нужных категорий. Файлы из разных категорий можно импортировать
   вместе; дубликаты товаров по паре SAP+PLU будут объединены.

Если появилась CAPTCHA, пройдите её вручную в обычном браузере либо прекратите
работу и повторите позже. Bookmarklet не решает CAPTCHA и не меняет поведение
защиты. Не используйте экспорт cookies, прокси или повторные автоматические
запросы для обхода проверки.

ЗАПУСК ИМПОРТА
--------------
Установите зависимости, если их ещё нет:
    python -m pip install pandas openpyxl pillow requests

Создайте папку 5ka_exports и положите туда сохранённые JSON-файлы.
Запустите:
    python import_5ka_exports_v7.py

Только Excel/CSV и ссылки на фото, без скачивания картинок:
    python import_5ka_exports_v7.py --no-photos

Результаты:
- pyaterochka_prices_v7.xlsx (листы «Товары» и «Сводка»)
- pyaterochka_prices_v7.csv
- photos5ka/<PLU>.jpg
- pyaterochka_import_report.json

КАКИЕ ПОЛЯ СОХРАНЯЮТСЯ
----------------------
SAP магазина, PLU, название, текущая цена, обычная цена, цена по акции,
процент скидки, промо-маркер, категории, URL фотографии, локальный файл фото,
ссылка на карточку, время выгрузки и исходный текст карточки.

ОГРАНИЧЕНИЯ И ВАЖНЫЕ ОГОВОРКИ
-----------------------------
- Экспортируется только то, что уже отрисовано в текущей вкладке. Он не
  переключает категории и не подгружает дополнительные страницы сам.
- Если список виртуализирован и часть карточек выгружается из DOM при прокрутке,
  экспортируйте отдельные участки после ручной прокрутки. Импортёр объединит их.
- SAP-код читается только из DeliveryPanelStore.selectedStore.sapCode. Если код
  не найден, в JSON он останется пустым — не приписывайте выгрузке SAP 35XY
  вручную, пока не проверите выбранный магазин.
- Цена на сайте/в приложении 5ka.ru может отличаться от цены в розничном магазине.
  Поэтому v7 помечает данные как каталог онлайн-доставки по выбранному адресу,
  а не как гарантированную цену на полке физического магазина.
- В JSON сохраняются только названия, PLU, отображённый текст, ссылки товара,
  URL картинок и SAP-код. Cookies, токены антибота и адрес доставки не сохраняются.

ИЗВЕСТНЫЕ ДАННЫЕ ПРОЕКТА
-----------------------
В успешном тесте прежнего парсера был выбран SAP 35XY; было получено 104 конечных
категории и проверены поля цены/фото на десяти товарах. Имя магазина в ответе API
отсутствовало. Старый checkpoint v4-v6 импортируется, где для него указан SAP
35XY из того успешного теста. Новые ручные выгрузки должны нести собственный SAP.

В import_5ka_exports_v7.py задано EXPECTED_SAP_CODE = "35XY". Если выбран другой
магазин, поменяйте это значение до импорта; скрипт напечатает предупреждение при
несовпадении или если у ручной выгрузки нет SAP-кода.
