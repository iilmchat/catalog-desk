# CD-ADR-004. Идемпотентность через `source_hash`, разделение времён

**Статус:** Accepted · **Дата:** 2026-11-24

## Контекст

Повторная загрузка того же JSON не должна дублировать наблюдения цен и снимки
карточек; при этом важно отличать время, когда данные были получены с сайта,
от времени их реального импорта в локальную базу.

## Решение

- `source_hash` = SHA-256 исходного файла; таблицы `exports`,
  `product_detail_imports` и `product_detail_history` — по одной записи на файл.
- `captured_at` — из JSON (время снимка), `imported_at` — `utc_now()` при вставке.
- `product_images.first_seen_at/last_seen_at` — по времени появления в выгрузках.

## Последствия

+ Повторный запуск импорта безопасен.
+ История цен остаётся упорядоченной даже при повторной загрузке старых файлов.
+ Lineage: `source_url`, `file_name`, `source_hash`, `collection_mode`.
− Требуется аккуратно мигрировать старые записи (сделано в V9).
