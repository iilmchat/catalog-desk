## 1. Требования

| Компонент | Версия | Когда нужен |
| :--- | :--- | :--- |
| Python | 3.10+ (проверен 3.12) | всегда |
| pip + venv | в комплекте | всегда |

| Chrome / Firefox / Edge | актуальный | сбор данных |

## 2. Установка

```powershell
git clone https://github.com/iilmchat/catalog-desk.git catalog-desk
cd catalog-desk
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements_v14.txt
```

> В репозитории хранятся только код и документация. База `*.sqlite3`, папки
> `5ka_exports/`, `5ka_product_details/`, `photos5ka/` и Excel/CSV-выгрузки
> исключены через `.gitignore` — их нужно сохранить отдельно и скопировать
> в корень проекта перед запуском, если вы переносите рабочую установку.

## 3. Запуск

```powershell
.\start_ui_v14.bat
# http://127.0.0.1:8767
```

Сервер:

- слушает только loopback, `--host` не может быть внешним адресом;
- перед обновлением создаёт резервные копии существующей базы (`*.pre_v14_backup.sqlite3` и `*.pre_v15.sqlite3`, если база уже есть);
- применяет идемпотентные миграции V14/V15, включая `chain`, составные ключи и отдельные состояния очередей по сетям;
- открывает браузер автоматически (`--no-browser` — отключить).

Проверка: `GET /api/health` → `ok=true`, `version="16.1.0-dev"`; также возвращается список поддерживаемых сетей.

## 4. Первый импорт

### 4.1. Экспорт каталога

1. Выберите сеть в переключателе Catalog Desk.
2. Откройте категорию выбранной сети в браузере и подгрузите товары («Показать ещё»).
3. Для Пятёрочки запустите `ui_v14/5ka_export_current_page_bookmarklet_v14.txt`, для Перекрёстка — `ui_v14/pr_export_current_page_bookmarklet_v14.txt`.
4. Сохранившийся JSON перетащите в раздел «Сбор и импорты» или загрузите через `/api/upload`.
5. Нажмите «Обновить базу». Импорт проверит SAP и домен источника; несоответствие сети остановит запись.

Повтор той же выгрузки ничего не дублирует: файл идентифицируется по SHA-256.

### 4.2. Импорт из командной строки

```powershell
python import_5ka_catalog_v9.py --chain 5ka --no-photos
python import_5ka_catalog_v9.py --chain 5ka --photos-only
python import_5ka_catalog_v9.py --chain perekrestok --input-dir C:\path\to\exports --no-photos
```

### 4.3. Что попадает в базу

| Таблица | Содержимое |
| :--- | :--- |
| `products` | текущее состояние товара: цена, скидка, категории, фото, ссылка |
| `price_history` | каждое наблюдение цены (`captured_at` из файла, `imported_at` — фактическое время импорта) |
| `exports` | журнал выгрузок, страница, SHA-256 |
| `product_categories` | история принадлежности к категориям |

> Цена — из онлайн-каталога для выбранного адреса доставки; она может отличаться от цены на полке.

## 5. Обогащение

### 5.1. Bookmarklet одной карточки

Откройте карточку выбранной сети. Для Пятёрочки используйте
`ui_v14/5ka_export_product_details_bookmarklet_v14.txt` (SAP `35XY`), для Перекрёстка —
`ui_v14/pr_export_product_details_bookmarklet_v14.txt` (SAP считывается из контекста магазина, fallback `XSEO`). Затем загрузите JSON через «Сбор и импорты» → «Импортировать доп. сведения».

### 5.2. Одиночное обновление и пакетный режим V16

1. Для одиночного обновления откройте карточку товара в Catalog Desk и нажмите «Обновить сведения»; нужен установленный userscript соответствующей сети.
2. Для пакетного режима установите `ui_v14/5ka_batch_enrichment_v16.user.js` (Пятёрочка) или `ui_v14/pr_batch_enrichment_v16.user.js` (Перекрёсток).
3. Проверьте, что userscript включён на соответствующем домене.
4. В верхнем переключателе Catalog Desk выберите нужную сеть.
5. В «Массовом обогащении» выберите категорию, лимит (10–20 для первого теста) и паузу (12–60 сек).
6. «Начать пакет» → браузер последовательно открывает карточки и отправляет JSON на `http://127.0.0.1:8767`.
7. После лимита — следующий пакет. При CAPTCHA сбор останавливается; проверка решается вручную.

### 5.3. Очередь и фото

«Очередь обновления» показывает товары без состава/характеристик; «Дозагрузить фото»
подтягивает изображения по уже известным URL. Из галереи исключаются фото
блоков «Вам понравится» / «Похожие товары».

В интерфейсе:

- [ ] `/api/health` → `ok=true`, версия `16.1.0-dev`, список сетей содержит обе сети;
- [ ] «Каталог» показывает товары, поиск по названию работает;
- [ ] «Аналитика» строит график и топы изменений;

## 7. Устранение проблем

| Симптом | Причина | Решение |
| :--- | :--- | :--- |
| «Не найдена pyaterochka_catalog_v9.sqlite3» | база не скопирована в корень | положите базу рядом с `catalog_ui_server_v14.py` или запустите импортёр |
| Крокозябры в консоли | кодировка cp866 | `chcp 65001` перед запуском |
| Пакет остановился с CAPTCHA | antimot-проверка сайта | решите вручную, нажмите «Возобновить»; обход запрещён |
| SAP mismatch | SAP не соответствует выбранной сети | проверьте выбранную сеть, SAP и URL выгрузки; неправильный импорт отклоняется до записи |
| Состав пустой, хотя виден на странице | поле не извлеклось bookmarklet'ом | импортёр V15.1 пытается восстановить состав из `details_text`; при необходимости используйте повторную загрузку карточки |
| Порт 8767 занят | другой экземпляр сервера | `python catalog_ui_server_v14.py --port 8768` |
| Фото не скачиваются | недоступен `catalog-images.x5static.net` | проверьте сеть; повторите «Дозагрузить фото» |
