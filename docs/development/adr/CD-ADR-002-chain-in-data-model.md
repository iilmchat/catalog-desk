# CD-ADR-002. `chain` в модели данных, одна БД на все сети

**Статус:** Accepted (проект V15) · **Дата:** 2026-11-24

## Контекст

Ключ `(sap_code, plu)` кажется «уже многомагазинным», но SAP — код точки
доставки, а не сети. В тестовой выгрузке Перекрёстка 110 из 432 PLU совпадают
с базой Пятёрочки. Без `chain` нельзя отличить сеть при запросе без SAP,
нельзя сравнивать цены и нельзя безопасно запускать обогащение двух сетей.

## Решение

Добавить `chain` (`5ka`, `perekrestok`) во все таблицы с товарами; ключ стать
`(chain, sap_code, plu)`. Миграция v9 → v10 аддитивная, с backfill `chain='5ka'`.
SAP остаётся как контекст магазина/доставки внутри сети.

## Последствия

+ Появляется честное происхождение записи и безопасное сравнение сетей.
+ PLU можно использовать как кросс-сетевой идентификатор товара.
− Требуется обновить все SQL-запросы и UI (S15–S18).
− При неверном SAP возможна рассинхронизация detail и catalog (CD-008) — смягчается
  автоподстановкой SAP из `localStorage`.
