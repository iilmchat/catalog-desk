ПЯТЁРОЧКА — CATALOG DESK V10
============================
Локальный веб-интерфейс: Python (только стандартная библиотека) + чистый JavaScript.
Без Node.js, npm, CDN и внешних сервисов.

ЧТО ЕСТЬ В ИНТЕРФЕЙСЕ
---------------------
1. Обзор: число товаров, скидок, фото, снимков цен, категории, последние импорты и изменения.
2. Каталог: поиск по названию и PLU, фильтры по категории и наличию скидки, сортировка.
3. Карточка товара: фото, PLU, цены, дата первого появления, последнего наблюдения,
   даты импорта и график истории цены.
4. Изменения цен: повышение/снижение цены, завершение/изменение скидки и условий акции.
5. Сбор данных: загрузка JSON-файлов прямо через браузер, запуск V9-импортёра,
   список категорий и страниц, история выгрузок.
6. Скачивание Excel и CSV.

ВАЖНО: сервер слушает только 127.0.0.1 — доступен лишь на этом компьютере.

УСТАНОВКА В СУЩЕСТВУЮЩИЙ ПРОЕКТ V9
---------------------------------
1. Сделайте резервную копию папки проекта (желательно всего каталога).
2. Распакуйте ZIP V10 прямо в папку, где уже лежат:
   pyaterochka_catalog_v9.sqlite3
   import_5ka_catalog_v9.py
   5ka_exports\
   photos5ka\
3. Не заменяйте и не удаляйте pyaterochka_catalog_v9.sqlite3, 5ka_exports или photos5ka.
   ZIP намеренно НЕ содержит SQLite-базу и существующие фотографии.
4. В ZIP есть новый JSON категории «Рыба и морепродукты» (SAP 35XY, страница 8).
   Он добавлен в 5ka_exports\ и будет импортирован при первом нажатии «Импортировать выгрузки».
5. Установите зависимости импортёра, если ещё не устанавливали:
   python -m pip install -r requirements_v10.txt

ЗАПУСК ИНТЕРФЕЙСА
-----------------
Дважды щёлкните start_ui.bat
или выполните:
   python catalog_ui_server_v10.py

Браузер откроет:
   http://127.0.0.1:8765

Для остановки сервера вернитесь в чёрное окно и нажмите Ctrl+C.
Пока окно сервера открыто, интерфейс работает.

КАК ДОБАВИТЬ ВЫГРУЗКУ
---------------------
1. В обычном браузере откройте 5ka.ru и проверьте адрес доставки / SAP 35XY.
2. В категории откройте нужную страницу, прокрутите товары, чтобы карточки появились.
3. Нажмите закладку «Экспорт карточек 5ka V10».
4. JSON-файл скачивается браузером.
5. Во вкладке «Сбор данных» перетащите JSON в область загрузки или выберите файл.
6. Нажмите «Импортировать выгрузки».

Закладка V10 также экспортирует номер текущей страницы и номера страниц,
ссылки на которые видны в пагинации DOM. Это оценка по видимой разметке, а не
гарантированное общее число страниц. Для покрытия категории нужно экспортировать
каждую страницу отдельно. Список ссылок на категории экспортируется второй закладкой.

ИСТОРИЯ ЦЕН
-----------
Повторный экспорт той же страницы в другую дату создаёт новое наблюдение.
После импорта изменения цены, обычной цены, акции и её условий отображаются
в разделе «Изменения цен», а график — в карточке товара.
Неизменённые товары всё равно получают новое наблюдение.

ФОТОГРАФИИ
-----------
По умолчанию кнопка импорта использует --no-photos: URL сохраняются, уже скачанные
фото не трогаются. Флажок «Скачать недостающие фото» запускает импортёр без этого
флага, и он попробует скачать локально отсутствующие изображения.

ДАННЫЕ И БЕЗОПАСНОСТЬ
--------------------
- JSON загружается в 5ka_exports\; повторяющийся файл не дублируется по SHA-256.
- В SQLite ничего не удаляется; используется существующая база V9.
- Перед добавлением UI в exports добавляются только два необязательных поля:
  max_page_linked и visible_page_numbers. Существующие данные не переписываются.
- Сервер доступен только по 127.0.0.1. Не меняйте host на 0.0.0.0.
- Интерфейс показывает цены онлайн-каталога для выбранного адреса доставки;
  это не гарантия цены на полке.
- Сбор не обходит CAPTCHA. Если сайт показывает проверку, пройдите её вручную
  в браузере и не запускайте автоматические повторные запросы.

ЕСЛИ ИНТЕРФЕЙС НЕ ОТКРЫВАЕТСЯ
-----------------------------
1. Убедитесь, что окно start_ui.bat не закрыто.
2. Проверьте адрес http://127.0.0.1:8765
3. Если порт занят, запустите:
   python catalog_ui_server_v10.py --port 8766
   и откройте http://127.0.0.1:8766
4. Если сообщается, что база V9 не найдена, проверьте, что файл
   pyaterochka_catalog_v9.sqlite3 находится рядом с catalog_ui_server_v10.py.
