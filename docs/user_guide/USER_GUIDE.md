# Руководство пользователя Catalog Desk V14.0

Интерфейс открывается по адресу `http://127.0.0.1:8767` после запуска
`start_ui_v14.bat`. Полная установка — [GET_STARTED.md](../../GET_STARTED.md).

---

## 1. Разделы интерфейса

| Раздел | Что делает |
| :--- | :--- |
| **Обзор** | KPI: товаров, полнота данных, наблюдений цен, фотографий; покрытие категорий; последние изменения |
| **Каталог товаров** | поиск по названию/PLU, фильтр по категории и акции, сортировка, пагинация |
| **Аналитика цен** | график средней цены и скидки, топы скидок/роста/падения |
| **Изменения** | сравнение соседних наблюдений цены, фильтр «рост/снижение» |
| **Избранное** | сохранённые товары (`sap_code + plu`) |
| **Массовое обогащение** | пакетная загрузка карточек через userscript; очередь и статусы |
| **Сбор и импорты** | загрузка JSON, запуск импортёра, дозагрузка фото/деталей, экспорт, папки |

## 2. Карточка товара

Двойной клик по строке открывает модалку:

- цена, обычная/акционная цена, скидка;
- пищевая ценность и характеристики;
- полный видимый текст карточки (`details_text`);
- галерея фотографий и история цен (SVG-график);
- снимки дополнительных сведений (последние 20).

> Состав может отсутствовать в выделенном поле, но присутствовать в тексте —
> см. CD-003. До V15 его можно прочитать в «полном тексте карточки».

## 3. Сбор данных

### 3.1. Категории

Bookmarklet `5ka_export_categories_bookmarklet.txt` на странице каталога
создаёт JSON-чек-лист. Он не импортируется в базу, а используется как список
категорий для обхода.

### 3.2. Список товаров

1. Откройте категорию; нажмите «Показать ещё» столько раз, сколько нужно.
2. Запустите `5ka_export_current_page_bookmarklet_v14.txt`.
3. В разделе «Сбор и импорты» загрузите JSON и нажмите «Обновить базу».

Файл импортируется один раз (SHA-256). Повторная загрузка того же файла
пропускается. Для истории цен сохраняйте новые выгрузки тех же категорий.

### 3.3. Дополнительные сведения вручную

На карточке товара запустите `5ka_export_product_details_bookmarklet_v14.txt`,
введите SAP выбранного магазина (`35XY`), загрузите JSON через
«Импортировать доп. сведения».

### 3.4. Пакетное обогащение

1. Установите `5ka_batch_enrichment_v14.user.js` (Tampermonkey/Violentmonkey),
   разрешите `https://5ka.ru`.
2. Выберите категорию, лимит (для первого теста 10–20) и паузу (15–20 сек).
3. «Начать пакет» — вкладка сама переходит по карточкам, импорт идёт автоматически.
4. При CAPTCHA пакет остановится: решите проверку и нажмите «Возобновить».
5. После достижения лимита — «Продолжить / следующий пакет».

Для 2 500 карточек нужно около 13 пакетов по 200.

## 4. Очередь обновления

Статусы: `pending` (ожидает), `opened` (открыта), `exported` (JSON есть),
`processed` (импортировано), `skipped`. Индикатор заполненностиoji считает
состав, описание, БЖУ, характеристики и полный текст. Неполные карточки
V14 вернул в очередь автоматически.

## 5. Экспорт и папки

- `/files/excel`, `/files/csv` — выгрузки;
- «Открыть папку» — `5ka_exports`, `5ka_product_details`, `photos5ka`, `5ka_category_lists`;
- «Дозагрузить фото» — только по уже известным URL, без обхода сайта.

## 6. Ограничения

- Собирается только видимый DOM; скрытые API не используются.
- CAPTCHA решается вручную, обход запрещён.
- Цена относится к онлайн-каталогу для выбранного адреса доставки.
- Все времена UTC; SAP и сеть фиксируются в метаданных выгрузки.
- Поддержка Перекрёстка появится в V15 — см. [TODO.md](../../TODO.md).
