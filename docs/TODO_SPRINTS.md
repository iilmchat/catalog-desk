## После V16.1.0 — S23: надёжность сбора и качество данных

**Статус:** In Progress · **Дата планирования:** 2026-11-26  
**Связанные проблемы:** CD-024, CD-025

| Задача | Критерий приёмки |
| :--- | :--- |
| DOM-фикстуры Пятёрочки и Перекрёстка | Парсеры проходят тесты на реальных обезличенных HTML-фрагментах без сети |
| Разделение секций карточки | Отзывы, рекомендации и навигация не попадают в текст товара |
| Извлечение полей | Для состава/описания тестируются видимое, свёрнутое и отсутствующее состояния; отсутствующие данные не выдумываются |
| DOM-backed regression в CI | Изменение селекторов/парсеров выявляется до merge |
| Качество и происхождение полей | Для каждого поля доступны source, captured_at и состояние извлечения |
| Безопасные повторы | Retry имеет лимит, задержку, причину и не запускается бесконечно |
