V8 — НАКОПИТЕЛЬНАЯ БАЗА

Главное отличие от v7:
- добавлена долговременная SQLite-база pyaterochka_catalog_v8.sqlite3;
- каждый исходный файл импортируется только один раз по SHA-256;
- товары объединяются по SAP + PLU;
- история цен сохраняет каждое новое наблюдение из новой выгрузки;
- лист «Изменения цен» показывает разницу между соседними наблюдениями одного товара;
- «Прогресс категорий» фиксирует номера страниц, уже представленные в экспортах;
- Excel каждый раз пересобирается из SQLite и поэтому не теряет предыдущую историю;
- старые локальные фотографии v7 переиспользуются, если файл photos5ka/PLU.jpg уже существует.

Проверка:
- py_compile: успешно;
- 4 модульных теста: успешно;
- тестовый импорт пользовательского JSON: 432 товара, 432 цены, 120 скидок, 432 URL фото;
- тест двух снимков: 432 товара, 864 наблюдения, 1 изменение цены;
- повторный запуск не добавляет дубликаты источников.
