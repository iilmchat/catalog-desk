# Pyaterochka Catalog Desk V13.0

Локальный интерфейс Pure JavaScript + Python + SQLite для магазина SAP 35XY.

## Почему V13.0 открывается отдельно
V13.0 запускается на `http://127.0.0.1:8766`, а старые V11/V12 использовали порт 8765.
Так старый процесс больше не может незаметно показывать заголовок V11.1. В интерфейсе,
HTTP-заголовке сервера и консоли закреплена одна версия — V13.0.

## Установка
1. Остановите старый сервер (Ctrl+C), если он запущен.
2. Сделайте резервную копию папки проекта.
3. Распакуйте СОДЕРЖИМОЕ ZIP прямо в рабочую папку проекта (без создания
   дополнительной вложенной папки). ZIP не содержит вашу SQLite-базу, каталог JSON
   и фотографии — эти данные не заменяются.
4. Запустите `start_ui_v13.bat`.
5. Откройте `http://127.0.0.1:8766` (браузер откроется автоматически).

Python 3.11+; внешние фронтенд-зависимости, Node.js и npm не нужны.
Зависимости Python: `python -m pip install -r requirements_v13.txt`.

## Массовое обогащение
В левом меню откройте «Массовое обогащение».
- Фильтры: категория, статус, полнота данных и текстовый поиск.
- Приоритет: сначала ожидающие карточки с наименьшей заполненностью.
- «Открыть» открывает карточку товара в новой вкладке и отмечает задачу как открытую.
- «JSON готов» вручную отмечает, что закладка сохранила JSON.
- После загрузки JSON в разделе «Сбор и импорты» и нажатия «Импортировать доп. сведения»
  сервер автоматически переводит товар в статус «Обработано».
- «Пропустить» и «Вернуть» позволяют вести очередь вручную.
- Прогресс и статусы хранятся в таблицах `enrichment_tasks` и `enrichment_task_events`.

Данные извлекаются из видимой открытой страницы с помощью bookmarklet V13. Массовый
автоматический обход страниц и обход CAPTCHA не выполняются.

## Дополнительные операции
- «Сбор и импорты» — добавление JSON товаров, категорий и подробных карточек.
- «Дозагрузить фото» — скачивание изображений по URL, уже находящимся в локальной базе.
- Дополнительные фото появляются в галерее после импорта подробной JSON-карточки.
- SQLite остаётся единственным источником истины; экспорт Excel/CSV пересобирается импортёром.

## Проверка
```powershell
python -m unittest -v test_catalog_v13.py test_ui_v13.py
```
Также можно проверить JavaScript синтаксисом Node.js, если он установлен:
`node --check ui_v13/app.js`.

## Важно
V13.0 использует существующий `pyaterochka_catalog_v9.sqlite3` и добавляет только новые
таблицы очереди обогащения. Старые таблицы и записи не удаляются. Сначала сделайте резервную
копию базы перед первым запуском новой версии.
