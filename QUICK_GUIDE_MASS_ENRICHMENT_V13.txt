PYATEROCHKA CATALOG DESK V13.0 — БЫСТРЫЙ СТАРТ

ПОЧЕМУ ТЕПЕРЬ НЕ V11.1
Старая программа использовала порт 8765. V13.0 запускается на отдельном порту 8766,
а BAT запускает именно catalog_ui_server_v13.py. Поэтому в адресной строке должно быть:
http://127.0.0.1:8766
В шапке страницы и заголовке вкладки будет V13.0.

УСТАНОВКА
1. Остановите старый сервер в его окне через Ctrl+C.
2. Сделайте резервную копию папки проекта.
3. Распакуйте СОДЕРЖИМОЕ этого ZIP в текущую рабочую папку проекта:
   C:\Tools\ParserPyaterka\pyaterochka_project_v7
4. Не удаляйте pyaterochka_catalog_v9.sqlite3, photos5ka, 5ka_exports,
   5ka_product_details и другие ваши JSON-выгрузки.
5. Запустите start_ui_v13.bat.
6. Откройте http://127.0.0.1:8766.

МАССОВОЕ ОБОГАЩЕНИЕ
1. Откройте слева «Массовое обогащение».
2. По умолчанию показаны ожидающие карточки с неполными подробными сведениями.
3. Выберите категорию, статус или полноту данных; используйте поиск.
4. Нажмите «Открыть» в строке или «Открыть следующую карточку».
5. На странице 5ka.ru нажмите закладку подробной карточки V13 и сохраните JSON.
6. В очереди нажмите «JSON готов» (необязательно — это отметка для удобства).
7. Откройте «Сбор и импорты», загрузите JSON, нажмите «Импортировать доп. сведения».
8. После успешного импорта товар автоматически получит статус «Обработано».

СТАТУСЫ
Ожидает — карточка ещё не открывалась.
Открыта — открывали страницу товара.
JSON сохранён — вручную отмечено, что экспортированный файл сохранён.
Обработано — подробный JSON импортирован в локальную базу.
Пропущено — временно отложена; «Вернуть» возвращает её в очередь.

ПРОГРЕСС
Индекс заполненности считается по пяти блокам: состав, описание, пищевая ценность,
характеристики, полный текст карточки. Это технический индикатор присутствия полей,
а не оценка обязательности каждого поля для каждого типа товара.

ДОПОЛНИТЕЛЬНО
- «Дозагрузить фото» скачивает URL изображений, уже сохранённые в базе.
- Для дополнительных ракурсов сначала импортируйте подробный JSON, затем запускайте дозагрузку фото.
- V13 добавляет таблицы очереди и событий в существующую SQLite; старые записи не удаляются.
- Данные извлекаются только с открытых страниц. Автоматического обхода CAPTCHA нет.
