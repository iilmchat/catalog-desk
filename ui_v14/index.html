ПАКЕТНЫЙ РЕЖИМ V16

Обработать товары автоматически по очереди

РАБОЧИЙ ЦИКЛ

Как обогащать карточки

1Один раз установи userscript V16 в Tampermonkey или Violentmonkey.
2Выбери категорию, размер пакета и паузу. Нажми «Начать пакет».
3Обычный браузер по очереди откроет товары, прочитает только видимый DOM и отправит подробности в локальную SQLite-базу.
4После пакета нажми «Продолжить / следующий пакет». Если появится CAPTCHA, пройди её вручную и затем нажми «Продолжить».
Ручная закладка остаётся как запасной способ для отдельной карточки. Пакетный режим не обходит проверки, не использует скрытые API и не открывает страницы параллельно.
