# CD-ADR-003. Конфиг магазинов вместо копирования проекта

**Статус:** Accepted (проект V15) · **Дата:** 2026-11-24

## Контекст

В V14 все параметры сети захардкожены: `EXPECTED_SAP = "35XY"`, `https://5ka.ru/*`,
`catalog-images.x5static.net`, `Referer: https://5ka.ru/`, `py5ka-*` guard,
`@match` userscript'а, имена папок и префиксы JSON. Копирование проекта под
Перекрёсток приведёт к двум расходящимся веткам кода и «тихой» порче данных.

## Решение

Единый реестр `catalog_config.py`: `chain`, домены, префиксы URL, regex категорий,
хосты фото, Referer, разрешённые SAP, `source`-маркеры, имена папок, брендинг.
Адаптеры сборщиков различаются только конфигурацией и тонкими парсерами DOM.

## Последствия

+ Второй магазин добавляется записью в конфиг и адаптером.
+ Тесты параметризуются по сети.
− Требуется вынести ~20 разбросанных констант (CD-002, CD-010, CD-012, CD-013).
