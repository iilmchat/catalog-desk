## Как работать с реестром

1. Новая проблема → `CD-XXX` в [KNOWN_ISSUES.md](KNOWN_ISSUES.md), статус `Open`.
2. При взятии в работу → `In Progress`, ссылка на шаг.
3. Исправление → `Fixed` + версия; в commit message — `CD-XXX`.
4. Не баг, а ограничение → `Documented` с обоснованием.
5. Сводка внизу KNOWN_ISSUES обновляется в том же коммите.
