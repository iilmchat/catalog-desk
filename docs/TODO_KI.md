## Правила ведения

1. Новая проблема → `CD-XXX` в [KNOWN_ISSUES.md](KNOWN_ISSUES.md), статус `Open`.
2. Взята в работу → `In Progress` со ссылкой на PR/спринт.
3. Исправлена → `Fixed` с версией, тестом и ссылкой на коммит.
4. Осознанное ограничение → `Documented` с обоснованием и безопасным поведением.
5. Этот список — рабочая выборка; статус и описание истины берутся из KNOWN_ISSUES.
