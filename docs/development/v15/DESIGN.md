## 1. Цели

1. Добавить Перекрёсток как полноценную сеть без копирования кода и без потери данных Пятёрочки.
2. Сделать происхождение каждого поля известным: сеть, SAP, время снимка, время импорта, источник.
3. Подготовить базу к quality-control, аналитике, сравнению и умному поиску.
4. Сохранить политику DOM-only и CAPTCHA → стоп.

## 2. Не-цели V15

- Обход CAPTCHA, внутренние API X5, синхронизация с сайтом в реальном времени.
- Полная автоматизация ежедневного сбора (S22), внешний публичный API (S22).
- ML-нормализация названий: PLU уже является общим идентификатором X5.

## 4. Принципы

- **Один контракт:** `Export v2 = {schema_version:2, chain, store, source, collection_mode, captured_at, products|product}`.
- **Один ключ:** `(chain, sap_code, plu)`; SAP остаётся контекстом доставки.
- **Один парсер качества:** серверный fallback из `details_text`.
- **Идемпотентность:** SHA-256 файла, `captured_at` ≠ `imported_at`.
- **Документация в коммите:** CHANGELOG + KNOWN_ISSUES + отчёт.

## 7. Критерий успеха

В одной базе лежат две сети, каждая карточка знает свой источник и полноту,
а аналитика сравнивает один и тот же PLU между сетями с явной датой и ценой за кг.
