ПЯТЁРОЧКА — ЭТАП V8: НАКОПИТЕЛЬНАЯ БАЗА + ИСТОРИЯ ЦЕН
=====================================================

ЗАДАЧА
------
Собирать выгрузки видимого каталога 5ka.ru по выбранному магазину SAP 35XY,
объединять товары по паре SAP+PLU, хранить изменения цен и скидок между датами,
сохранять фото и формировать Excel.

V8 НЕ открывает 5ka.ru и НЕ обходит CAPTCHA. Источник данных — JSON-файлы,
которые пользователь самостоятельно сохраняет bookmarklet'ом из видимой страницы.

УСТАНОВКА
---------
1. Распакуйте ZIP прямо в существующую папку проекта v7 (например, C:\Tools\ParserPyaterka\pyaterochka_project_v7). В ней рядом должны оказаться import_5ka_catalog_v8.py и папка 5ka_exports.
2. При необходимости установите зависимости:
   python -m pip install -r requirements_v8.txt
3. Не удаляйте папку 5ka_exports и файлы JSON — это первичные снимки каталога.
4. Старый импортёр v7 можно оставить; v8 создаёт отдельную базу и отдельные выходные файлы.

ЗАПУСК
------
   python import_5ka_catalog_v8.py

Без скачивания фотографий:
   python import_5ka_catalog_v8.py --no-photos

Если выбран другой SAP:
   python import_5ka_catalog_v8.py --expected-sap 35XY

ПОВТОРНЫЕ ЗАПУСКИ
-----------------
V8 хранит состояние в pyaterochka_catalog_v8.sqlite3.
Каждый исходный JSON идентифицируется SHA-256. Повторный запуск с теми же JSON
не создаёт повторных строк истории. Новые выгрузки (новые снимки/даты/страницы)
добавляются в базу. Excel и CSV каждый запуск пересобираются из SQLite.

ВЫХОДНЫЕ ФАЙЛЫ
--------------
pyaterochka_catalog_v8.sqlite3 — основная накопительная база SQLite.
pyaterochka_catalog_v8.xlsx — листы:
  Товары             — последнее известное состояние каждого SAP+PLU.
  Сводка             — показатели наполнения базы.
  История цен        — все наблюдения цен из разных выгрузок.
  Изменения цен      — изменения текущей/обычной цены и процента скидки.
  Прогресс категорий — страницы, которые уже были выгружены, и число PLU.
  Экспорты           — список обработанных файлов с датой и URL страницы.
pyaterochka_catalog_v8.csv — текущий список товаров.
pyaterochka_catalog_v8_report.json — машинный отчёт.
photos5ka/           — локальные JPG; старые имена v7 переиспользуются.

ВАЖНО О ПОЛНОТЕ
---------------
Экспорт bookmarklet'а берёт только карточки, уже присутствующие в DOM текущей
страницы. Если категория разбита на страницы, каждую страницу нужно открыть
обычным браузером, вручную подгрузить товары и экспортировать отдельно.
Лист «Прогресс категорий» показывает страницы, встречавшиеся в файлах, но не
может самостоятельно узнать общее число страниц на сайте. Поэтому выгруженные
страницы — не доказательство полноты всей категории.

ИСТОРИЯ ЦЕН
-----------
История создаётся только с момента первого снимка, импортированного в v8.
Старые v7 JSON-файлы можно положить в 5ka_exports: они будут добавлены как
первые точки истории. Чтобы увидеть изменение, нужен минимум второй снимок
того же PLU с более поздней датой выгрузки.
Изменение цены рассчитывается между соседними наблюдениями этого PLU.

ЦЕНЫ
----
Цены относятся к онлайн-каталогу 5ka.ru для выбранного адреса доставки и могут
отличаться от цены на полке физического магазина. Проверяйте SAP в каждом JSON.
Не подставляйте SAP вручную, если он отсутствует в экспорте.

ПРОВЕРКА
--------
Запустить тесты без доступа к сайту и без скачивания фотографий:
   python -m unittest -v test_import_5ka_v8.py
